Demonstration 32

Conformal correlation

A recent paper proposes correlating class membership across conformal prediction sets and reading the result as a map of which classes a classifier confuses. Three experiments on a synthetic classifier with known confusability show what the statistic responds to. The close reading is on the critique page.

The question the authors want the matrix to answer is which classes the classifier confuses. The direct answer is the soft confusion matrix,

$$C_{ab} = \mathbb{E}\big[\,p_b \,\big|\, y = a\,\big],$$

the average probability the classifier assigns to class \(b\) over images whose true class is \(a\). It is directional, it uses the probabilities at full resolution, and it needs no calibration set and no threshold. The authors never compute it. Every panel below puts the conformal correlation matrix beside the soft confusion matrix on the same data and asks which one answers the question.

We build a classifier whose mistakes we control. There are \(H = 10\) classes. For an image with true class \(y\), the classifier’s logits and reported probabilities are

$$\ell_h = m\,\mathbf{1}[h = y] + G_{yh} + \varepsilon_h, \qquad \varepsilon_h \sim N(0,1) \text{ independently}, \qquad p_h = \frac{e^{\ell_h}}{\sum_{k=1}^{H} e^{\ell_k}}, \qquad h = 1, \dots, H.$$

The margin \(m\) sets the accuracy. The matrix \(G\) sets the confusions: \(G_{yh} > 0\) pushes probability from images of class \(y\) onto class \(h\), and \(G\) need not be symmetric. Panel A uses \(G_{01} = G_{10} = c\) and zero elsewhere. Panel B uses \(G_{01} = \theta c\) and \(G_{10} = (1-\theta) c\). Panel C draws a symmetric \(G\) at random. In every case the truth is known exactly.

From this classifier we draw \(n = 1{,}000\) labeled calibration images and 3,000 test images. The sets are the adaptive prediction sets of Romano, Sesia and Candès, which the paper uses. Each calibration image gets the score

$$s = \sum_{k :\, p_k \ge p_y} p_k \;-\; U\, p_y, \qquad U \sim \mathrm{Unif}(0,1),$$

the probability mass at and above the true class, less a random share of the true class’s own mass. The threshold \(q\) is the \(\lceil (n+1)(1-\alpha) \rceil\)-th smallest calibration score. For a test image the classes are taken in decreasing order of \(p_h\) while the mass before them is below \(q\), and the last class taken is kept with probability equal to the fraction of its mass needed to reach \(q\). Coverage is then exact at \(1-\alpha\).

For each test image write \(z_h = 1\) if class \(h\) is in its set and \(0\) otherwise. The conformal correlation matrix is

$$\rho_{ij} = \frac{\mathbb{E}[z_i z_j] - \mathbb{E}[z_i]\,\mathbb{E}[z_j]} {\sqrt{\operatorname{Var}(z_i)\,\operatorname{Var}(z_j)}},$$

with the expectations taken over the 3,000 test images, exactly as the authors define it. Since the \(z_h\) are zeros and ones, each entry is a phi coefficient.

Beside it, each panel computes the soft confusion matrix \(C\) defined above from the same probability vectors. Panel C also uses the symmetric version, the mean pairwise product \(S_{ij} = \mathbb{E}[p_i p_j]\), since the truth there is symmetric. Each panel then changes one thing about \(G\) or the inputs and shows how the two matrices respond.

A. The entries are pinned by inclusion rates

Here exactly one pair of classes, 0 and 1, is genuinely confusable. Every other pair is cleanly separated. The left heat map is the conformal correlation matrix at the chosen \(\alpha\). The right is the soft confusion matrix, the mean probability the classifier puts on each column class for images of each row class.

In this experiment the classifier separates 44 of the 45 pairs perfectly. Their entries in the conformal correlation matrix are all the same negative number, and that number is set by how often each class is included in a set. It says nothing about the classes.

Write \(p_i\) for the fraction of test sets that contain class \(i\). Two classes that never appear in the same set have \(\mathbb{E}[z_i z_j] = 0\), so their entry is

$$\rho_{ij} = \frac{0 - p_i p_j}{\sqrt{p_i(1-p_i)\,p_j(1-p_j)}} = -\sqrt{\frac{p_i\,p_j}{(1-p_i)(1-p_j)}}.$$

With ten balanced classes and singleton sets, \(p_i = 1/10\) for every class and every such entry equals \(-1/9\). The dashed line in the lower plot is this formula evaluated at the observed inclusion rates. It lies on top of the blue line, the average of the 44 entries.

The sliders change the inclusion rates without changing the classifier. Moving \(\alpha\) changes the set sizes, so all 44 entries move together. Adding class imbalance makes common classes appear in more sets than rare ones, so the 44 entries spread out in a pattern that copies the class frequencies. Raising the share of hard inputs, on which the classifier has no margin and so returns a large set, makes all 45 entries positive, including the 44 pairs the classifier still separates perfectly on every other input.

The authors read a negative entry as dissimilarity and a positive entry as similarity. Here the negative entries are a function of \(\alpha\) and the class frequencies only, and the positive entries are produced by input difficulty with no similarity between the classes at all.

B. A symmetric object cannot carry a directional claim

The authors read from a positive entry that the classifier “is much more likely to misclassify images of class 91 as class 30 than as class 95.” A correlation matrix is symmetric. This panel puts a fixed total amount of confusion between classes 0 and 1 and slides how much of it runs each way: at \(\theta = 1\) images of class 0 are pulled toward class 1 and images of class 1 are clean, at \(\theta = 0\) the reverse.

The two soft confusion entries cross: one rises as the other falls, and together they say which way the confusion runs. The conformal correlation entry is a single curve symmetric about one half. It takes the same value at \(\theta\) and at \(1-\theta\), so it cannot distinguish a classifier that mislabels 0 as 1 from one that mislabels 1 as 0. The authors’ claim to a “superset of the information conveyed by the confusion matrix” fails on counting alone. The matrix has \(H(H-1)/2\) distinct off diagonal entries and directional confusion has \(H(H-1)\).

C. Resolution collapses as the sets shrink

Now every pair of classes has its own confusion strength, drawn at random and held fixed. The question is whether a statistic can rank the 45 pairs by that hidden truth. Left: the conformal correlation entry against the true strength, at the chosen \(\alpha\). Middle: the mean pairwise product of probabilities \(\mathbb{E}[p_i p_j]\) against the same truth. Right: the rank correlation with the truth as a function of \(\alpha\).

The soft statistic has no \(\alpha\) to choose and ranks the pairs well at every setting. The conformal statistic sits at the pinned floor from panel A across most of the range of true confusability and separates only the few strongest pairs, so its rank correlation with the truth is lower at every \(\alpha\), and it falls further as \(\alpha\) grows and the sets shrink toward singletons, because singleton sets carry no pairwise information at all. The authors sweep \(\alpha\) over four values and present the dependence as adaptability. It is the statistic recovering, coarsely, what the threshold discarded. The randomization in APS adds noise of its own that a probability based statistic does not have. Untick the box to remove it and watch the sets grow instead.

Takeaway. The conformal correlation matrix is the phi coefficient of a thresholded softmax, and the coverage guarantee concerns the true label alone. The probabilities the sets were cut from answer the authors’ question better at every setting of every slider.

The paper is Perlo, Chiasserini, De Veciana and Malandrino, Computer Communications 247 (2026) 108398.
